# EEG-Based Seizure Detection Using Machine Learning

Machine-learning project using the CHB-MIT Scalp EEG Database to classify
5-second EEG windows as seizure or non-seizure activity.

## Dataset

CHB-MIT Scalp EEG Database (PhysioNet)

## Planned Pipeline

Raw EEG
→ Preprocessing
→ 5-second windowing
→ Feature extraction
→ Classical machine learning
→ Patient-independent evaluation

## Status

Environment and project infrastructure setup.
